# Expense Report App (Phase 1)

Desktop expense report application built with PySide6 + SQLite.

## Run

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python -m expense_report_app.app
```

## Dependencies

- PySide6
- Pillow (future receipt/image handling)
- reportlab (future PDF generation)
